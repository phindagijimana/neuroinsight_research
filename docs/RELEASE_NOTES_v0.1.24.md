# NeuroInsight v0.1.24

UI polish: Transfer-first Home, unified workspace layout, responsive navigation.

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon) | `NeuroInsight-0.1.24-arm64.dmg` |
| Windows | `NeuroInsight-Setup-0.1.24.exe` |
| Linux | `NeuroInsight-0.1.24.AppImage` / `.deb` |

Engine image: `ghcr.io/phindagijimana/nir-allinone:v0.1.24`

## Highlights

- **Jobs UI** — 2×2 submit grid (Compute | Pipeline, Subject path | Resources);
  unified header; Transfer link in subtitle.
- **Transfer UI** — unified page shell; navy Remote tab; auto-browse when already
  connected; improved empty states.
- **Navigation** — responsive hamburger menu; active-tab pill styling.
- **Home** — Transfer-first capability copy.

## Upgrade

Use **Help → Check for Updates…** (macOS menu bar) or install the DMG from
[Releases](https://github.com/phindagijimana/neuroinsight_research/releases/tag/desktop-v0.1.24).

After updating: **NeuroInsight → Settings → Stop engine → Start engine → Open Workspace**.
